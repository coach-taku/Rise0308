# 要求定義書 - RISE NOTE

## プロジェクト概要

**アプリ名**: RISE NOTE  
**対象チーム**: KUKI GYMRATS  
**キャッチコピー**: 本気になれば、何者にもなれる

---

## 要求一覧

### 1. ユーザー管理

- 選手（プレイヤー）とコーチの2種類のロールが存在する
- 名前の選択と**個別パスワード**によるログイン認証
- ログイン後はロールに応じた画面に遷移する
- 管理者（スタッフ）は専用の管理画面から選手・スタッフの登録・情報修正・パスワード変更ができる

### 2. 選手（プレイヤー）向け機能

- **日々の練習記録（デイリーノート）**: 練習内容・自己評価・メモを記録できる
- **目標設定（マンダラチャート）**: 目標を構造化して設定・可視化できる
- **タイムライン（グループ共有）**: チーム全体の投稿・活動を閲覧できる。選手名・マネージャー名で絞り込めるメンバー検索機能を備え、入力するごとにリアルタイムで表示が絞り込まれる
- **ダッシュボード**: 自分の活動状況・ポイントを確認できる。ボトムナビには「ホーム・記録・目標・スタッツ・カルテ・共有」の6つのボタンを配置する
- **カルテ（身体測定・MAX測定）**: INBODY測定・MAX測定の結果を入力・閲覧できる。ダッシュボードのボトムナビから直接アクセスできる

### 3. コーチ向け機能

- **ダッシュボード**: 選手全体の活動状況を一覧で確認できる
- **選手名検索**: ユーザー管理画面で選手名を入力するとリアルタイムに絞り込みが行われ、目的の選手を即座に見つけられる
- **チームダッシュボード（疲労度・睡眠時間の平均推移）**: 任意の複数選手を手動で選択し、選択した選手の疲労度・睡眠時間の平均値を過去3週間分の折れ線グラフで確認できる
- **カルテ閲覧**: 各選手のINBODY測定（身長・体重・体脂肪率・筋肉量）およびMAX測定（ベンチプレス・スクワット・デッドリフト）の全期間推移を個人グラフとチーム平均の重ね合わせで確認できる
- **タイムライン（過去データ閲覧）**: カレンダーで日付を選択することで、任意の過去日付の選手振り返り・コンディションデータを閲覧できる。日付未選択時は過去90日間の全件を表示する
- **大会管理（トーナメント）**: 大会情報の登録・管理ができる
- **ユーザー管理**: 選手・スタッフの新規登録、情報修正（名前・ポジション等）、パスワードの確認・変更ができる
- **Session RPE管理**: その日の練習時間（分）を入力・保存し、選手が入力した疲労度と掛け合わせてSession RPE（自覚的運動強度×時間）を自動計算・一覧表示できる。強度管理・ピリオダイゼーションの判断材料として活用する（コーチ専用・選手側には非表示）
- **Session RPE長期推移グラフ**: Session RPEタブに折れ線グラフを追加。チーム平均Session RPE（練習時間×チーム平均疲労度）の推移を過去30日・60日・90日から選択して表示できる。各日の値はツールチップで確認可能。疲労の蓄積や回復傾向を長期的かつ直感的に把握できる（コーチ専用）

### 4. PWA対応（ホーム画面追加）

- スマートフォンのホーム画面にアイコンを追加できる
- ホーム画面から起動するとスタンドアロンモード（全画面）で表示される
- オフライン時も基本的な画面が表示される（エラー画面にならない）
- iPhone（Safari）・Android（Chrome）両方で動作する

### 5. カルテ機能（身体測定・MAX測定記録）

- 3ヶ月に1度の身体測定データ（身長・体重・体脂肪率・筋肉量）を記録・蓄積できる
- ウェイトトレーニングのMAX測定データ（ベンチプレス・スクワット・デッドリフト）を記録・蓄積できる
- 蓄積されたデータの推移を折れ線グラフで視覚的に確認できる
- 過去の記録を一覧で閲覧でき、編集・削除も可能

## 利用者・環境

- **主要デバイス**: スマートフォン（iOS / Android）
- **主要ブラウザ**: Safari（iOS）、Chrome（Android）
- **使用場面**: 練習前後、移動中、就寝前など日常的に使用

## 非機能要件

- モバイルファーストのUI設計
- 日本語対応
- Supabase Auth による認証
- Vercel でホスティング

### 6. 記録の正確反映とモチベーション向上機能（2026-06-18 追加）

- **記録数・参加日数の正確な集計**: 選手の過去データをすべて対象に累計記録数・練習参加日数を正しく算出し、15日目以降も途切れることなく表示されること
- **連続記録日数（ストリーク）の表示**: 毎日途切れず記録を続けている日数を算出し、ダッシュボードに表示する
- **記録完了時のポジティブフィードバック**: 記録を保存した際に、連続記録日数と励ましのメッセージを画面中央にポップアップ（カード）で表示する

---

### 7. スタッツ管理機能（2026-06-23 追加）

- **スタッツデータのインポート（コーチ専用）**: コーチがCSVファイルをアップロードすることで、試合ごとのスタッツデータをシステムに一括登録できる
- **スタッツ閲覧（コーチ・選手共通）**: 統合されたスタッツ画面からコーチ・選手双方が試合パフォーマンスデータを確認できる
- **KPI可視化**: 3P 33% / 2P 50% / FT 75% の達成状況を緑（達成）・赤（未達）でカラーコーディングして一目で把握できる
- **PER40換算表示**: 出場時間によらず40分あたりに正規化した値で選手間・試合間の公平な比較ができる
- **折れ線グラフ推移**: 試合ごとの得点・リバウンド・アシストおよびシュート成功率の推移を折れ線グラフで確認できる
- **チームスタッツ一覧（コーチ専用）**: 全選手のスタッツを横断的に閲覧し、選手ごと・試合種別ごとに絞り込める
- **手動選手管理**: 選手アカウントとスタッツデータの紐付けはCSV内の選手名を使用した手動管理（自動マッチングなし）

---

### 8. グロースマインドセット自動スコアリングおよび教員向けダッシュボード（2026-07-14 追加）

- **LLMによる自動スコアリング**: 生徒が振り返りを入力・保存した際に、サーバーサイドでLLM（Gemini API）を呼び出し、4段階のルーブリックに基づき「グロースマインドセット」変容度を自動判定・数値化する
- **個人情報の保護（匿名化フィルター）**: LLMへの送信データは氏名等の個人特定情報を除外し、仮IDとテキストのみを送信するプライバシー保護処理を行う
- **セキュアなAPI設計**: APIキーはサーバーサイドのみで管理し、ブラウザ（クライアント側）には一切露出しない
- **教員向けメタ認知スコアダッシュボード**: 算出された全選手のスコアを一覧化・グラフ化し、心理的状態の低下（スコアが閾値を下回った選手）をアラートハイライト表示する教員専用画面

---

### 9. マンダラチャート大会周期連動・アーカイブ・目標更新サイクル機能（2026-07-14 追加）

- **指導者主導の目標更新トリガー機能（コーチダッシュボード）**: コーチがコーチ用ダッシュボードの「次期目標設定フェーズを開始」ボタンを押すと、全生徒のアプリに通知バナーが表示され、目標更新フロー（振り返り入力→新チャート作成）が起動する
- **大会振り返り（リフレクション）ステップ**: 新しいマンダラチャートを作成する直前に、前回のチャートの達成度・課題・Plan B（改善行動戦略）を入力・保存する専用ステップを経由する。入力後にLLMによるメタ認知スコアリングが非同期で実行される
- **マンダラチャートのアーカイブ（履歴）機能**: 過去のマンダラチャートを「2026年 インターハイ予選」などのタームごとに保存し、生徒自身がいつでも過去の目標と振り返り（成長の軌跡）を閲覧できる
- **目標更新時のタイムライン自動共有**: 新しいマンダラチャートが完成した際に、自動的にタイムライン投稿として記録され、チームメイトとの相互支援構造を促進する

### 10. 10ヶ条評価・SSCアクションプラン連動機能（2026-07-26 追加）

- **10ヶ条評価のアプリ内統合**: Googleフォームで運用していた10ヶ条アンケート（全30問・10カテゴリ）をRISE NOTE内に統合する
- **アンケート自動アサイン（コーチ専用）**: 指導者がワンボタンで全選手に評価タスクを配信する。ペア設定テーブルを参照し、自己評価 + 他者評価タスクを自動生成する
- **レーダーチャートでギャップ視覚化（選手向け）**: 自己評価（実線）と他者評価の平均（点線）を重ね合わせたレーダーチャートで、自分の強み・課題を客観視できる
- **Start/Stop/Continue入力（選手向け）**: 評価結果をもとに、新しく始めること・やめること・続けることを入力・保存できる
- **アクションプランの自動連動**: 入力したSSCプランが「日々の入力」の目標候補と「マンダラチャート」のサジェストバナーに自動反映される
- **ダッシュボード通知バナー（選手向け）**: 未回答の評価タスクがある場合、選手ダッシュボード上部にオレンジ色の通知バナーを表示する
- **コーチ向け評価一覧・ギャップ自動検知**: 全選手の自己評価・他者評価スコアを一覧表示し、乖離が大きい選手（差1.0以上）を赤ハイライトと「！ ギャップ大」バッジで自動的に強調表示する

### 12. 10ヶ条評価削除機能・連絡事項/TODOリスト追加（2026-07-29 追加）

- **【機能追加】10ヶ条評価配信削除機能**: 指導者がコーチダッシュボードから送信済みの回答依頼（配信）を削除できる。削除時は関連するタスク・回答データも連動して消去され、未回答選手のダッシュボード通知バナーも自動的に消える
- **【機能追加】連絡事項・TODOリストの追加**: 指導者・選手の双方向からホーム画面最上部に連絡事項やTODOを発信できる機能を追加する
- **【機能追加】チェックボックスと未完了者数表示**: 連絡事項・TODOにチェックを入れると自分の画面から非表示になるが完了履歴として保持される。指導者画面では未チェック人数を表示する
