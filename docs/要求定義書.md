# 要求定義書 - RISE NOTE

## プロジェクト概要

**アプリ名**: RISE NOTE  
**対象チーム**: KUKI GYMRATS  
**キャッチコピー**: 本気になれば、何者にもなれる

---

## 要求一覧

### 1. ユーザー管理

- 選手（プレイヤー）とコーチの2種類のロールが存在する
- 名前の選択と**個別パスワード**によるログイン認証
- ログイン後はロールに応じた画面に遷移する
- 管理者（スタッフ）は専用の管理画面から選手・スタッフの登録・情報修正・パスワード変更ができる

### 2. 選手（プレイヤー）向け機能

- **日々の練習記録（デイリーノート）**: 練習内容・自己評価・メモを記録できる
- **目標設定（マンダラチャート）**: 目標を構造化して設定・可視化できる
- **タイムライン**: チーム全体の投稿・活動を閲覧できる
- **ダッシュボード**: 自分の活動状況・ポイントを確認できる

### 3. コーチ向け機能

- **ダッシュボード**: 選手全体の活動状況を一覧で確認できる
- **チームダッシュボード（疲労度・睡眠時間の平均推移）**: 任意の複数選手を手動で選択し、選択した選手の疲労度・睡眠時間の平均値を過去3週間分の折れ線グラフで確認できる
- **カルテ閲覧**: 各選手のINBODY測定（身長・体重・体脂肪率・筋肉量）およびMAX測定（ベンチプレス・スクワット・デッドリフト）の全期間推移を個人グラフとチーム平均の重ね合わせで確認できる
- **タイムライン（過去データ閲覧）**: カレンダーで日付を選択することで、任意の過去日付の選手振り返り・コンディションデータを閲覧できる。日付未選択時は過去90日間の全件を表示する
- **大会管理（トーナメント）**: 大会情報の登録・管理ができる
- **ユーザー管理**: 選手・スタッフの新規登録、情報修正（名前・ポジション等）、パスワードの確認・変更ができる

### 4. PWA対応（ホーム画面追加）

- スマートフォンのホーム画面にアイコンを追加できる
- ホーム画面から起動するとスタンドアロンモード（全画面）で表示される
- オフライン時も基本的な画面が表示される（エラー画面にならない）
- iPhone（Safari）・Android（Chrome）両方で動作する

### 5. カルテ機能（身体測定・MAX測定記録）

- 3ヶ月に1度の身体測定データ（身長・体重・体脂肪率・筋肉量）を記録・蓄積できる
- ウェイトトレーニングのMAX測定データ（ベンチプレス・スクワット・デッドリフト）を記録・蓄積できる
- 蓄積されたデータの推移を折れ線グラフで視覚的に確認できる
- 過去の記録を一覧で閲覧でき、編集・削除も可能

## 利用者・環境

- **主要デバイス**: スマートフォン（iOS / Android）
- **主要ブラウザ**: Safari（iOS）、Chrome（Android）
- **使用場面**: 練習前後、移動中、就寝前など日常的に使用

---

## 非機能要件

- モバイルファーストのUI設計
- 日本語対応
- Supabase Auth による認証
- Vercel でホスティング
